# Advantages of open source software

The most obvious advantage of open source software is that it costs nothing to download. For a student that matters: 

LibreOffice does most of what Microsoft Office does, and I do not need to pay for a licence. But price is the smallest part of the story.

Open source means anyone can read the code. This makes it possible to check what a program really does with your data, which is important for researchers handling sensitive material and for municipalities that must answer to their citizens. Anyone can also change the code. If a tool lacks a feature, a developer can add it, instead of waiting for a company to decide it is worth the money.

Another advantage is independence. If a company closes down or drops a product, closed software can simply disappear. With open source the code is still there, and others can keep the project alive. 

Open file formats help too: documents made in LibreOffice can be opened by many programs, so my work does not depend on one supplier.
Open source also builds on shared work. Projects reuse each other's code, and large ones like Firefox are developed by communities around the world. 

Finally, open source supports open research. If a scholar uses an open tool, others can repeat the analysis and see exactly how a result was reached.

But free to download does not mean free to make, as the next page shows.
